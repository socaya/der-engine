# DER Visualiser requirements package

This bundle provides an implementation baseline: full Markdown, rendered PDF, requirements traceability, NFRs, acceptance catalogue and a compatibility manifest. It contains **no executable app**, and has not been tested against a live DHIS2 2.41–2.44 instance.

**Important:** DER Analytics is authoritative for computation and lineage; Visualiser governs chart/pivot/map/dashboard/story presentation, sharing and exports.
