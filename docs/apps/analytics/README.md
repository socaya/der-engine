# DER Analytics documentation package

This is a design specification, not a deployed or certified DHIS2-compatible analytics engine.

Files: comprehensive Markdown, PDF, requirements traceability CSV, compatibility and dataset manifest JSON, example test vectors CSV.

Baseline hospital aggregate package: 15 parent datasets / 175 native sections / 1,039 aggregate data elements. Data element quantity denotes metadata catalogue size, not the number of automatically derivable metrics.

The specification preserves no claim of full program indicator or native period parity without version-specific tests.
