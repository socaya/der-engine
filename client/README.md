# DER Client

React/TypeScript web starter; development port `5174`.

## Commands

`npm install` then `npm run dev`. `npm run build` checks TypeScript and creates production assets. `npm run test` runs starter component tests.

## Scope

Local supported DHIS2 workflow access; integration not yet implemented. The current screen is an honest starter interface and **does not** simulate successful business transactions. Use existing DHIS2 applications where possible; document permissions, loading, offline-WAN, edge-disconnected, error and recovery states for every added screen.
